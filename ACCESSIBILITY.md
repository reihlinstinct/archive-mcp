# Accessibility statement

Our target is SI 5568 level AA, aligned with WCAG 2.2 A/AA.
A full SI 5568/WCAG conformance audit has not been completed.

## Scope

This service has one small web page (the archive upload form on the Worker root). The page uses semantic HTML, a labelled password field, a labelled file input, keyboard-operable controls and system fonts, and is usable at mobile widths.

## Evidence and adjustments

The page is plain HTML with no custom widgets; browser-native inputs keep focus and screen-reader behavior standard.

## Known limits

Automated tests are not compliance certification. A complete keyboard, screen-reader, zoom/reflow and contrast evaluation remains to be done.
